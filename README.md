# 캠프베이스 — 함께 쓰는 캠핑 앱 설정 안내서

한 사람이 준비물을 체크하거나 기록을 남기면 앱을 가진 모두의 화면에 바로 반영되는 캠핑 앱이에요.
안드로이드는 APK로 설치하고, 아이폰은 웹 주소를 홈 화면에 추가해서 써요.

처음 한 번만 아래 순서대로 설정하면 돼요. 전부 무료이고, 30분 정도 걸려요.

## 준비물

- 구글 계정 (Firebase용)
- GitHub 계정 (무료, APK를 대신 만들어주는 곳) — 없으면 github.com에서 가입
- 이 폴더(`campbase-app`)와 기존 데이터 파일(`campbase-backup-claude.json`)

---

## 1단계. Firebase 프로젝트 만들기 (공유 저장소)

1. [console.firebase.google.com](https://console.firebase.google.com)에 구글 계정으로 들어가요.
2. **프로젝트 만들기(추가)** → 이름은 `campbase` 같은 걸로 → Google 애널리틱스는 **사용 안 함**으로 두고 만들어요.
3. 결제 정보 등록은 필요 없어요. 무료 요금제(Spark)로 충분해요.

## 2단계. 데이터베이스 만들고 규칙 붙여넣기

1. 왼쪽 메뉴에서 **Databases & Storage(데이터베이스 및 스토리지) → Firestore** → **데이터베이스 만들기(Create database)**.
   (메뉴 이름이 **Firestore Database**로 보이면 그걸 누르면 돼요. 버전(에디션)을 물어보면 **Standard**를 골라요.)
2. 위치는 **asia-northeast3 (서울)** 을 고르세요. 한 번 정하면 못 바꿔요.
3. 모드를 물어보면 **프로덕션 모드**로 만들어요. (선택지 이름이 조금 달라도 괜찮아요. 규칙은 바로 다음에 바꿔요.)
4. 만들어지면 위쪽 **규칙(Rules)** 탭으로 가서, 적혀 있는 내용을 전부 지우고 이 폴더의 `firestore.rules` 파일 내용을 그대로 붙여넣은 뒤 **게시**를 눌러요.

> 이 규칙은 "앱을 가진 사람은 누구나 읽고 쓸 수 있게, 대신 캠프베이스가 쓰는 칸만 열어두기"예요.
> 이 단계를 빼먹으면 앱에서 "공유 저장소 접근이 거부됐어요"라는 안내가 떠요.

## 3단계. 설정값을 앱에 넣기

> ✅ 이미 완료됨 — `docs/firebase-config.js`에 Firebase 프로젝트 `campbase-f5df5` 설정값이 들어가 있어요.
> 아래는 나중에 다른 프로젝트로 바꿀 때 참고용이에요.

1. 왼쪽 위 **프로젝트 개요** 옆 톱니바퀴 → **프로젝트 설정**.
2. 아래쪽 **내 앱**에서 웹 아이콘 **`</>`** 을 눌러요.
3. 앱 닉네임은 `campbase`, **Firebase Hosting 설정은 체크하지 않고** 앱 등록.
4. 코드가 나오면 그중 `const firebaseConfig = { ... };` 부분만 복사해요. (`apiKey`, `projectId` 등이 들어 있는 부분)
5. 이 폴더의 `docs/firebase-config.js` 파일을 메모장(맥은 텍스트 편집기)으로 열어서,
   `const firebaseConfig = { ... };` 부분을 복사한 내용으로 바꾸고 저장해요.
   맨 아래 `window.FIREBASE_CONFIG = firebaseConfig;` 줄은 지우지 마세요.

> 이 값들은 비밀번호가 아니라 "어느 저장소로 연결할지" 알려주는 주소 같은 거라, 공개 저장소에 올려도 괜찮아요.

## 4단계. GitHub에 올리기 (여기서 APK가 자동으로 만들어져요)

1. [github.com](https://github.com) 로그인 → 오른쪽 위 **+** → **New repository**.
2. 이름은 `campbase`, **Public**(공개)으로 만들어요. 비공개로 하면 친구들이 APK를 받을 수 없어요.
3. 만든 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 눌러요.
4. `campbase-app` 폴더 **안에 있는 것 전부**를 끌어다 놓고 **Commit changes**를 눌러요. 폴더 자체가 아니라 폴더 안의 내용물이에요.
5. 올린 뒤 저장소 첫 화면에 아래 항목이 보이면 성공이에요.
   `.github` · `assets` · `docs` · `keystore` · `capacitor.config.json` · `firestore.rules` · `package.json` · `README.md`

> **맥 사용자 주의:** `.github` 폴더는 이름이 점으로 시작해서 Finder에서 숨겨져 있어요.
> Finder에서 **Cmd + Shift + .(마침표)** 를 누르면 보이니, 그 상태에서 전부 선택해서 올리세요.
> 그래도 `.github`가 안 올라갔다면: **Add file → Create new file** → 파일 이름에 `.github/workflows/build-apk.yml` 입력 →
> 이 폴더의 같은 파일 내용을 붙여넣고 Commit 하면 돼요.

## 5단계. APK 받기

1. 저장소 위쪽 **Actions** 탭을 누르면 **Build APK** 작업이 돌아가고 있어요. 5~10분 기다리면 초록색 체크가 떠요.
   - 작업이 안 보이고 "워크플로를 켜라"는 안내가 나오면 **I understand my workflows, go ahead and enable them** 을 누른 뒤,
     왼쪽 **Build APK** → 오른쪽 **Run workflow** 를 눌러요.
2. 저장소 첫 화면 오른쪽 **Releases** 에 `campbase.apk`가 생겨요.
3. 친구들에게 보낼 링크예요. 항상 최신 버전을 받아요.
   ```
   https://github.com/내아이디/campbase/releases/latest/download/campbase.apk
   ```

## 6단계. 휴대폰에 설치

1. 안드로이드 폰에서 위 링크를 열면 `campbase.apk`가 다운로드돼요.
2. 파일을 열면 "출처를 알 수 없는 앱" 설치를 허용할지 물어봐요. 허용하고 설치해요.
3. Play 프로텍트가 "알 수 없는 앱"이라고 경고하면 **세부정보 → 무시하고 설치**를 눌러요. 직접 만든 앱이라 스토어 검증이 없어서 나오는 경고예요.
4. 앱을 열었을 때 상단에 **"자동 저장 켜짐 · 함께 쓰는 중"** 이 보이면 연결 성공이에요.

## 7단계. 기존 데이터 옮기기 (한 사람이 한 번만)

1. 앱에서 **Settings → 백업 가져오기** → 파일 선택에서 `campbase-backup-claude.json`을 골라요.
   (폰으로 파일 옮기기 번거로우면 PC에서 아래 8단계 웹 주소로 열어서 가져와도 똑같아요.)
2. **가져오기 → 바꾸기**를 누르면 모든 사람 화면에 반영돼요.
3. 참고: 캠핑 기록 2개(홍천·가평)와 장비 3개는 처음에 들어 있던 예시 데이터예요. 필요 없으면 지우세요.

## 8단계. (선택) 아이폰 친구용 웹 주소

아이폰은 APK를 설치할 수 없어서 웹 주소로 써요. 데이터는 APK와 똑같이 공유돼요.

1. GitHub 저장소 **Settings → Pages**.
2. **Source: Deploy from a branch**, Branch는 **main**, 폴더는 **/docs** 로 고르고 **Save**.
3. 몇 분 뒤 `https://내아이디.github.io/campbase/` 주소가 생겨요.
4. 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

---

## 앱을 고치거나 새 버전을 올릴 때

- GitHub 저장소에서 파일을 바꾸면(예: `docs/index.html` 교체, `docs/firebase-config.js` 수정) APK가 **자동으로 다시 만들어져요.**
- 폰에서는 같은 링크로 다시 받아 설치하면 기존 앱 위에 덮어 설치돼요. 데이터는 Firebase에 있어서 그대로예요.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 앱에 "미리보기 모드예요"가 뜸 | 3단계 설정값이 안 들어갔어요. GitHub에서 `docs/firebase-config.js`를 연필 아이콘으로 고치고 Commit → 새 APK 설치 |
| "공유 저장소 접근이 거부됐어요" | 2단계 규칙을 **게시**하지 않았어요. 규칙 탭에서 붙여넣고 게시 |
| "연결 안 됨"이 뜸 | 인터넷이 없는 상태에서 처음 열었어요. 연결된 곳에서 한 번 열면 그 뒤로는 오프라인에서도 열려요 |
| Actions에 빨간 X | 실패한 단계를 눌러 나오는 빨간 오류 부분을 캡처해서 Claude에게 보여주세요 |
| 설치할 때 "패키지 충돌" | 기존 앱을 지우고 다시 설치하세요. 데이터는 Firebase에 있어서 사라지지 않아요 |

## 꼭 알아둘 점

- **주소나 APK를 가진 사람은 누구나 수정·삭제할 수 있어요.** 로그인 없이 쓰기로 한 방식이라서예요.
  **Settings → 백업 내보내기**로 가끔 백업을 남겨두면, 실수로 지워도 **백업 가져오기**로 되돌릴 수 있어요.
- 캠핑장처럼 신호가 약한 곳에서도 앱이 열리고, 체크한 내용은 인터넷이 연결되면 자동으로 동기화돼요.
- Home 위젯 켜기/끄기는 각자의 기기에만 적용돼요. 다른 사람 화면에는 영향이 없어요.
- APK 서명키(`keystore` 폴더)는 업데이트할 때 덮어 설치가 되도록 고정해둔 개발용 키예요. 플레이스토어에 올릴 때는 새 키를 만들어야 해요.
