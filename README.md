# 캠프베이스 — 구글 로그인으로 쓰는 나의 캠핑 앱 설정 안내서

캠핑 준비물 체크, 내 캠핑 장비, 다녀온 캠핑장 후기를 모아두는 앱이에요.
**구글 계정으로 로그인**하면 사람마다 자기 공간에 저장되고, 같은 계정으로 로그인한 폰·PC끼리는 바로 동기화돼요.
다른 사람에게는 내 기록이 보이지 않아요. 친구·가족과는 **그룹**을 만들어 준비물 체크리스트와 장비를 함께 볼 수 있어요.
안드로이드는 APK로 설치하고, 아이폰은 웹 주소를 홈 화면에 추가해서 써요.

처음 한 번만 아래 순서대로 설정하면 돼요. 전부 무료예요.

## 준비물

- 구글 계정 (Firebase용)
- GitHub 계정 (무료, APK를 대신 만들어주는 곳)

---

## 1단계. Firebase 프로젝트 만들기

> ✅ 이미 완료됨 — 프로젝트 `campbase-f5df5`.

1. [console.firebase.google.com](https://console.firebase.google.com)에 구글 계정으로 들어가요.
2. **프로젝트 만들기(추가)** → Google 애널리틱스는 **사용 안 함** → 만들기. 무료 요금제(Spark)로 충분해요.

## 2단계. 데이터베이스 만들고 규칙 붙여넣기

1. 왼쪽 메뉴 **Firestore Database** → **데이터베이스 만들기** (에디션을 물어보면 **Standard**).
2. 위치는 **asia-northeast3 (서울)**. 한 번 정하면 못 바꿔요. 모드는 **프로덕션 모드**.
3. 위쪽 **규칙(Rules)** 탭에서 적혀 있는 내용을 전부 지우고, 이 저장소의 `firestore.rules` 내용을 그대로 붙여넣은 뒤 **게시**.

> 이 규칙은 "구글로 로그인한 본인만 자기 공간(`users/내 번호/...`)을 읽고 쓰기, 그룹 데이터는 그 그룹 멤버만"이에요.
> 그룹 참여는 유효한 초대 코드가 있어야만 되고, 멤버 내보내기·그룹 이름 변경·삭제는 그룹장만 할 수 있게 규칙이 막아줘요.
> 예전 공유 저장소 자리는 지금 **로그인한 사람만 읽기 전용**이에요(아래 "전환 기간 끝내기" 참고).
> **규칙은 GitHub에 올려도 자동으로 바뀌지 않아요.** `firestore.rules`가 바뀔 때마다 여기에 다시 붙여넣고 게시해야 해요.

## 3단계. 구글 로그인 켜기

1. 왼쪽 메뉴 **Authentication(인증)** → **시작하기**.
2. **로그인 방법(Sign-in method)** 탭 → **Google** → **사용 설정** 켜기 → 프로젝트 지원 이메일에 내 이메일 선택 → **저장**.
3. **설정(Settings)** 탭 → **승인된 도메인(Authorized domains)** → **도메인 추가** → `jskzoom4.github.io` 입력 → 추가.
   (아이폰·PC 웹 주소에서 로그인하려면 필요해요. `localhost`, `campbase-f5df5.firebaseapp.com`은 원래 들어 있어요.)
4. 안드로이드 앱 SHA-1 등록 ✅ 이미 완료됨 — 프로젝트 설정 → 내 앱 → Android(`com.campbase.app`)에
   `9F:9E:A1:D9:CB:5D:15:FE:10:C4:E1:30:2D:48:A1:7A:D3:7E:11:9D`가 있으면 돼요. (`keystore/debug.keystore`의 지문이에요.)
5. `android-config/google-services.json` ✅ 이미 올라가 있음. 나중에 SHA-1이나 로그인 설정을 바꾸면
   프로젝트 설정 → 내 앱 → Android 앱에서 **google-services.json**을 다시 받아 이 파일을 바꿔주세요.

## 4단계. 설정값을 앱에 넣기

> ✅ 이미 완료됨 — `docs/firebase-config.js`에 `campbase-f5df5` 설정값이 들어가 있어요.
> 다른 프로젝트로 바꿀 때: 프로젝트 설정 → 내 앱 → 웹 앱(`</>`)의 `const firebaseConfig = { ... };` 부분을 복사해서
> `docs/firebase-config.js`의 같은 부분을 바꾸면 돼요. 맨 아래 `window.FIREBASE_CONFIG = firebaseConfig;` 줄은 지우지 마세요.
> 이 값들은 비밀번호가 아니라 "어느 저장소에 연결할지" 알려주는 주소 같은 거라 공개 저장소에 올려도 괜찮아요.

## 5단계. APK 받기

APK는 GitHub가 자동으로 만들어줘요. 저장소 위쪽 **Actions** 탭 → **Build APK** 에서 진행 상황을 볼 수 있어요(5~10분).

| 어디에 올렸나 | APK가 올라가는 곳 | 누가 받나 |
|---|---|---|
| **main** 브랜치 | 저장소 오른쪽 **Releases** 의 `campbase.apk` | 친구들 (최신 링크) |
| 다른 브랜치 / PR | 그 Actions 실행 화면 맨 아래 **Artifacts** 의 `campbase-apk-번호` | 나 (머지 전 테스트) |

- 친구들에게 보낼 링크(항상 main의 최신 버전):
  ```
  https://github.com/jskzoom4/CampBase/releases/latest/download/campbase.apk
  ```
- **머지 전에 내 폰에서 먼저 테스트하기:** Actions → 해당 브랜치의 **Build APK** 실행(초록 체크) 클릭 →
  맨 아래 **Artifacts** 의 `campbase-apk-번호` 를 눌러 받기 → zip 파일 압축을 풀면 `campbase.apk` → 설치.
  (Artifacts는 GitHub에 로그인해야 받을 수 있어요. 폰 브라우저에서 GitHub에 로그인하거나, PC에서 받아 폰으로 옮기세요.)
- `android-config/google-services.json`이 없으면 빌드가 "google-services.json 없음" 오류로 멈춰요.

## 6단계. 휴대폰에 설치

1. 안드로이드 폰에서 위 링크를 열면 `campbase.apk`가 다운로드돼요.
2. 파일을 열어 "출처를 알 수 없는 앱" 설치를 허용하고 설치해요.
3. Play 프로텍트가 경고하면 **세부정보 → 무시하고 설치**. 직접 만든 앱이라 스토어 검증이 없어서 나오는 경고예요.
4. 앱을 열면 **Google로 시작하기** → 폰의 구글 계정 선택 → 상단에 **"자동 저장 켜짐 · 내 계정에 저장"** 이 보이면 성공이에요.
   한 번 로그인하면 다음부터는 바로 열려요. 로그아웃은 **Settings → 내 계정 → 로그아웃**.

## 7단계. 예전 공유 데이터 가져오기 (각자 한 번씩)

로그인 기능이 생기기 전에는 모두가 한 저장 공간을 같이 썼어요. 그 데이터는 그대로 남아 있고, 필요한 사람이 자기 공간으로 복사하면 돼요.

1. 로그인한 뒤 **Settings → 기존 공유 데이터 가져오기**.
2. 몇 개가 있는지(캠핑 기록·장비·체크리스트·요리 재료 체크) 확인 창이 떠요. **가져오기**를 누르면 내 공간으로 복사돼요.
3. 원본은 그대로 남고, 이미 내 공간에 같은 항목이 있으면 덮어쓰지 않고 건너뛰어요. 여러 번 눌러도 중복되지 않아요.

## 그룹으로 함께 쓰기

그룹 멤버끼리는 **Checklist(준비물)와 Gear(장비)** 를 함께 보고 고칠 수 있어요. 캠핑 기록·Home·요리는 항상 나만 보는 개인 공간이에요.

1. **그룹 만들기:** Settings → 내 그룹 → **그룹 만들기** → 이름 입력. 만든 사람이 그룹장이에요.
2. **친구 초대:** 그룹의 **초대 코드** 버튼 → 6자리 코드가 나와요(7일 동안 유효). **코드 복사**로 친구에게 보내요. 그룹 멤버라면 누구나 코드를 만들 수 있어요.
3. **참여하기(친구):** Settings → 내 그룹 → **코드로 참여** → 코드 입력 → 그룹 이름 확인 → 참여.
4. **함께 쓰기:** Checklist·Gear 탭 위쪽의 칩에서 **[내 공간 | 그룹 이름]** 을 골라요. 고른 공간은 그 기기에 기억돼요.
5. **내 것 옮기기:** 내 공간의 체크리스트 제목 옆 보내기 아이콘, 또는 Gear의 **그룹으로 보내기**로 그룹에 **복사**해요(내 것은 그대로 남아요).
6. **담당자·장비 주인:** 그룹 체크리스트 항목 옆 **담당** 버튼으로 챙길 사람을 정하고, **내 담당** 필터로 내 몫만 볼 수 있어요.
   그룹 장비는 수정 화면에서 **주인**(누구 장비인지)을 고르고, 장비 목록 위에서 주인별로 거를 수 있어요.
7. **관리:** 멤버 목록 보기, 나가기(내가 만든 항목은 그룹에 남음). 그룹장은 멤버 내보내기·이름 변경·그룹 삭제를 할 수 있어요. 그룹장은 나갈 수 없고, 그룹을 삭제해야 해요.

## 8단계. (선택) 아이폰·PC용 웹 주소

1. GitHub 저장소 **Settings → Pages** → **Source: Deploy from a branch**, Branch **main**, 폴더 **/docs** → **Save**.
2. 몇 분 뒤 `https://jskzoom4.github.io/CampBase/` 주소가 생겨요. (3단계의 승인된 도메인 추가가 필요해요)
3. 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**. 로그인은 구글 로그인 창(팝업)으로 해요.

## 전환 기간 끝내기 (모두 새 버전으로 옮긴 뒤)

`firestore.rules` 안의 **"전환 기간"** 블록이 예전 공유 저장소 자리예요.

1. **1단계 — 읽기 전용 ✅ 적용됨:** 로그인한 사람만 읽기(가져오기)만 되고, 쓰기·삭제는 막혀요.
   로그인 없는 예전 APK(build-3 이하)는 더 이상 쓸 수 없어요. 앱에서는 예전 데이터가 남아 있을 때만 "기존 공유 데이터 가져오기" 버튼이 보여요.
2. **2단계 — 삭제 (나중에, 더 가져올 사람이 없을 때):**
   1. Firebase 콘솔 → **Firestore Database → 데이터** 탭.
   2. 맨 왼쪽 목록의 **최상위** 컬렉션 `campingLogs`, `gear`, `checklists`, `cookingChecks`, `app` 각각 → 컬렉션 이름 옆 **⋮** → **컬렉션 삭제** → 이름을 입력해 확인.
      (`users`, `groups`, `groupInvites`는 **절대 지우지 마세요.** 모두의 개인·그룹 데이터예요.)
   3. 저장소의 **`firestore.rules.final`**(전환 기간 블록을 미리 지워 둔 초안) 내용을 규칙 탭에 전부 붙여넣고 게시.
   4. 그 뒤 Claude에게 "firestore.rules.final을 firestore.rules로 바꿔줘"라고 요청해서 저장소도 맞춰 두세요.
   앱은 예전 데이터가 없거나 읽을 수 없으면 가져오기 버튼을 알아서 숨겨요. 앱 업데이트는 필요 없어요.

## 앱을 고치거나 새 버전을 올릴 때

- 브랜치에 올리면 테스트용 APK(Artifacts), main에 반영하면 친구용 APK(Releases)가 **자동으로** 만들어져요.
- 폰에서는 같은 링크로 다시 받아 설치하면 기존 앱 위에 덮어 설치돼요. 데이터는 Firebase에 있어서 그대로예요.
- `firestore.rules`가 바뀌었으면 2단계처럼 콘솔에 다시 붙여넣고 게시하세요.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| "Firebase에서 Google 로그인이 아직 켜져 있지 않아요" | 3단계 2번(Google 사용 설정)을 해주세요 |
| 웹에서 "로그인 허용 목록에 없어요" | 3단계 3번(승인된 도메인에 `jskzoom4.github.io` 추가) |
| APK에서 "구글 로그인 설정(SHA-1 등록)이 맞지 않아요" | 3단계 4번 SHA-1 확인 → google-services.json 다시 받아 교체 |
| 웹에서 로그인 창이 안 뜸 | 브라우저의 팝업 차단을 풀고 다시 눌러주세요 |
| "저장소 접근이 거부됐어요" / "저장 권한이 없어요" | 2단계 새 규칙을 **게시**하지 않았어요. 규칙 탭에서 최신 `firestore.rules`를 붙여넣고 게시 |
| 그룹 만들기·참여가 안 됨 | 그룹 규칙이 들어간 최신 `firestore.rules`를 게시했는지 확인하세요 |
| "만료된 코드예요" | 초대 코드는 7일만 쓸 수 있어요. 그룹 멤버에게 새 코드를 받으세요 |
| 앱에 "미리보기 모드예요"가 뜸 | 4단계 설정값이 안 들어갔어요 |
| "연결 안 됨"이 뜸 | 인터넷이 없는 상태에서 처음 열었어요. 연결된 곳에서 한 번 열면 그 뒤로는 오프라인에서도 열려요 |
| Actions에 빨간 X | 실패한 단계를 눌러 나오는 빨간 오류 부분을 캡처해서 Claude에게 보여주세요 |
| 설치할 때 "패키지 충돌" / "앱이 설치되지 않았습니다" | 기존 앱을 지우고 다시 설치하세요. 데이터는 Firebase에 있어서 사라지지 않아요. (build-9 이하 APK는 서명키가 매번 달라서, 고정 키로 바뀐 첫 업데이트는 한 번 지우고 설치해야 해요) |

## 꼭 알아둘 점

- 내 기록은 내 구글 계정에만 저장되고, 다른 사람은 볼 수도 고칠 수도 없어요. 그룹 공간에 올린 체크리스트·장비만 그 그룹 멤버와 함께 봐요.
- 체크리스트 항목·리스트·장비·캠핑 기록을 지우면 화면 아래에 **"삭제했어요 · 되돌리기"**가 5초 동안 떠요. 실수로 지웠으면 바로 누르세요.
- **Settings → 백업 내보내기**로 가끔 백업을 남겨두면, 실수로 지워도 **백업 가져오기**로 되돌릴 수 있어요(내 계정 데이터만 바뀌어요).
  그룹장은 **Settings → 내 그룹 → 백업 내보내기/가져오기**로 그룹의 체크리스트·장비도 백업할 수 있어요.
- APK는 하루 한 번 새 버전이 있는지 확인해서, 있으면 위쪽에 **"새 버전이 있어요 · 받기"**를 보여줘요. Settings 맨 아래에서 지금 빌드 번호를 볼 수 있어요.
- Home 위젯 켜기/끄기는 계정에 저장돼서, 같은 계정으로 로그인한 다른 기기에도 똑같이 적용돼요.
- 캠핑장처럼 신호가 약한 곳에서도 앱이 열리고, 체크한 내용은 인터넷이 연결되면 자동으로 동기화돼요.
- APK 서명키(`keystore` 폴더)는 절대 바꾸지 마세요. 이 키의 SHA-1이 Firebase에 등록돼 있어서, 바꾸면 구글 로그인과 덮어 설치가 모두 안 돼요.
